Button: the primary interactive control for calls to action (Donate, Apply for cost-share, Attend meeting).

```jsx
<Button variant="primary" href="/donate">Donate</Button>
<Button variant="secondary">Learn more</Button>
```

Variants: primary (solid water-blue), secondary (outlined), ghost (text-only, used in nav), accent (solid land-green, for a secondary program CTA). Sizes: sm, md, lg.
