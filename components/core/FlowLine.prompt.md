FlowLine: the brand's signature wave (from the FCWID wordmark), stretched full-width as a section divider.

```jsx
<FlowLine />
<FlowLine tone="land" static />
```

On the homepage, its draw progress is tied to scroll position: rolls out scrolling down, retracts scrolling up. Everywhere else, use `static` for a plain solid line with no scroll behavior. Use sparingly, one per page keeps it a signature, not wallpaper.
