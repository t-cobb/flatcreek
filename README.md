# FCWID Website — design preview

Static preview of the Flat Creek Watershed Improvement District website, built from
the `design_handoff_fcwid_website` bundle. Served via GitHub Pages for team review.

These are **design prototypes**, not production code: pages are plain HTML that load
React + Babel from a CDN and transpile the components in `components/` at runtime.

Bank Restoration, Scott Lane, and Ongoing Projects are intentionally placeholders —
real copy is pending from the client.

Images were re-encoded for web (max 1800px, JPEG q68); originals are in the handoff bundle.
Marked `noindex` — not intended for search engines.
